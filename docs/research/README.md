# User research notes

7 conversations held 20–22 November 2026 (in person and by phone/message) with 1 experienced hiker, 3 beginners and
3 club organizers, using the guide in docs/VALUE_CASE.md §6. Notes were written up afterwards with help from an AI
assistant; answers are summarised, not word-for-word.

One file per conversation (`YYYY-MM-DD-<profile>.md`). What we learned, and what changed in the app because of it,
is in docs/VALUE_CASE.md §2 (assumptions and their status).
